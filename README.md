# Клиент Alzy

Preact и Vite. Главная `/` — лендинг CRM, `/demo` — сайт студии «Линия», `/register` — регистрация, `/app` — кабинет владельца, `/platform` — кабинет платформы. Личные страницы записи и виджеты расположены по `/b/SLUG/book` и `/b/SLUG/widget`.

Запуск Vite: `npm install && npm run dev`. На порту 5173 API не проксируется. `npm run build` создаёт `dist`, а `npm run preview` показывает сборку на порту 4173. Koa отдаёт только `/api`; для работы функций с API фронтенд должен обращаться к нему с того же адреса через конфигурацию хостинга.

Сборка использует `preact-iso` и создаёт статический HTML для `/`, `/demo` и `/register`. Маршруты компаний и кабинетов обрабатываются в браузере; для прямого входа на них хостинг должен отдавать `index.html`.

Проверки стиля: `npm run lint` и `npm run format:check`. Форматирование всех исходных файлов: `npm run format`.

Код виджета генерируется в кабинете. Он вставляет iframe с публичной страницей компании. Общие инструкции находятся в [корневом README](../README.md).
